# 研究资料

本目录保存 AgentArbor 的研究报告、早期总览、早期工程规划和外部参考研究。

这些资料有长期参考价值。它们记录了项目为什么存在、未来可能长成什么样、能力资产如何组织、AgentApp 如何出生和演化、治理如何介入、如何避免局部最优等问题。

## 使用方式

- 可以作为产品定位、架构设计和模块拆分的输入。
- 可以被吸收到 `../开发指南/` 的稳定结论中。
- 不能直接替代当前开发指南。
- 不能因为命名、阶段目标或架构表述与当前文档不同就删除。

## 目录说明

- `认知演化型Agent工作台形态研究.md`：以“工作如何跨时间形成理解”为叙事主线，研究 Space、Conversation、Knowledge Revision 与 Agent 如何共同构成可持续演进的个人工作台。
- `深度研究报告.md`：早期深度研究总报告。
- `深度研究v0.1/`：分章节深度研究资料，包括基础、研究迭代、系统架构、模型、决策框架、AgentApp 标准、图表和提示词资料。
- `早期总览/`：早期定位、当前规划和项目计划书。
- `早期工程规划/`：早期工程蓝图、能力资产体系、多智能体集群方案和第一版路线资料。
- `早期架构决策/`：早期架构判断，作为历史研究输入保留。
- `工程研究/`：与当前工程决策直接相关的依赖能力盘点、实现边界和评测研究。
- `工程研究/AgentArbor当前运行风险与工程债.md`：登记当前生产入口仍有代码证据的运行风险、前端结构性风险与验证债务，并维护已关闭历史问题。
- `工程研究/AgentArbor-0.3.1工具系统设计与评测研究报告.md`：五版工具设计的来源、演进、最终方案、双模型评测与盲审闭环。
- `工程研究/工具系统V3研究.md`：工具定义保真、三层边界、MCP 成本门控和 Pi active set/Session 隔离研究。
- `参考资料/`：能力资产、智能体工程、模型、协议、沙箱、权限、评测、模型厂商资料和外部项目分析相关参考研究。

## 重要边界

本目录不是当前执行计划。后续要采用其中观点，必须先合并进 `../开发指南/` 或形成明确实现任务。
