# 架构设计

本目录保存 AgentArbor 仍有长期参考价值的架构设计资料。

这里只保留产品架构、协议边界、工作区结构和历史植物学架构资料。历史经验、推进记录、阶段计划、文档结构治理流水、准备包和草案包不放在这里。

当前产品架构事实源是 [ADR-0022-AgentArbor桌面通用Agent与双运行时架构](产品架构/ADR-0022-AgentArbor桌面通用Agent与双运行时架构.md)。[ADR-0018-AgentArbor原生概念树架构](产品架构/ADR-0018-AgentArbor原生概念树架构.md) 已被部分取代，保留为历史脉络和术语背景。其他 ADR 和详细架构资料作为背景材料保留，不能覆盖当前开发指南。

如果想先看一份面向读者的总览，可先读 [产品说明](产品架构/README.md)。

## 目录说明

- `产品架构/`：AgentArbor 产品形态、双运行时架构、智能体体系、Plan、治理回流和历史植物学资料。
- `协议边界/`：官方兼容层、AgentArbor 原生协议和开发工具层边界。
- `工作区结构/`：根目录、`docs/`、`.agentarbor/` 和长期项目布局相关决策。

## 使用规则

- 可以作为未来架构判断的输入。
- 不能直接替代 `../开发指南/03-系统架构/README.md`。
- 与当前开发指南冲突时，保留原文，吸收前重新判断。
- 不新增经验流水、推进记录、阶段计划或无验证草案。
