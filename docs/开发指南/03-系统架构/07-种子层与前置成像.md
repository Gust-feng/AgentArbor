# 种子层与前置成像

## 定位

Seed Cluster 是 AgentArbor 的启动门。它把用户提示词中的原始想象转化为可审阅、可迭代、可批准的 Seed Packet。

Seed Cluster 不属于地下 Root System，也不属于地上执行组织。它不执行正式任务，不写长期资产，不生成 Growth Plan。

## 输入与输出

输入是 Imagination：

- 用户原始提示词。
- 已知背景。
- 用户补充信息。
- 初始约束和偏好。

输出是 Seed Packet：

```text
seed-packet/
  00-用户原始想象.md
  01-目标成像.md
  02-非目标与边界.md
  03-假设与缺失信息.md
  04-最小化搜索.md
  05-反驳与风险.md
  06-可选方向.md
  07-用户决策记录.md
  08-启动建议.md
  handoff-to-root.md
  seed.meta.json
```

## Seed Cluster 职责

Seed Cluster 是固定低自由度集群，建议包含：

| 成员 | 职责 |
| --- | --- |
| Intent Framer | 理解用户想象，形成目标成像 |
| Scope Splitter | 拆解目标、非目标和边界 |
| Assumption Mapper | 列出假设、缺失信息和待确认点 |
| Minimal Researcher | 做最小化搜索，只补齐启动前必要事实 |
| Devil Advocate | 反驳、找漏洞、防局部最优 |
| Feasibility Checker | 做初步可行性判断 |
| Risk Gate | 检查权限、成本、风险和不可逆动作 |
| Seed Synthesizer | 汇总成 Seed Packet |

## 用户确认循环

```text
Imagination
  -> Seed Cluster
  -> Seed Packet Draft
  -> User Review
  -> Revise or Approve
  -> Handoff to Root
```

用户可以要求修改 Seed Packet。只有确认后的 Seed Packet 才允许进入 Soil 并触发 Initial Rooting。

## 禁止事项

- 不启动 Root System。
- 不生成 Growth Plan。
- 不调度 Branch / Leaf。
- 不创建 Capability Asset。
- 不把 Seed Packet 当长期事实源。
- 不绕过用户确认门执行高风险动作。
