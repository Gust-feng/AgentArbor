# 模型与契约

本章定义 AgentArbor 未来实现必须先稳定的数据模型。代码可以晚出生，但契约不能含混。

本章中的 Seed Packet、Root Brief、Growth Plan、Workflow IR、Root Callback、Run Memory、Experience Candidate、Capability Asset 和 Path Bias 共同决定系统如何从一次运行中收获可复用倾向，而不是把历史经验停留在自然语言总结里。
