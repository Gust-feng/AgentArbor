# 智能体应用标准目录

## 目标

智能体应用标准目录用于承载由 AgentArbor 孕育出的可运行智能体应用。它必须服务执行、验证、维护和导出，而不是追求表面完整。

## 建议目录

```text
agentapp/
  arbor.json
  README.md
  agents/
  capabilities/
  workflows/
  prompts/
  adapters/
  tests/
  docs/
  lineage/
```

## 目录职责

- `arbor.json`：AgentApp 入口描述。
- `README.md`：人类可读入口。
- `agents/`：AgentApp 内部 agent 定义。
- `capabilities/`：能力声明和依赖。
- `workflows/`：Workflow IR 或平台工作流适配。
- `prompts/`：提示词资产。
- `adapters/`：外部平台、模型或工具适配。
- `tests/`：测试和验收样例。
- `docs/`：AgentApp 自身文档。
- `lineage/`：谱系记录和验证证据。

## 出生规则

这些目录只在智能体应用真实生成时创建。AgentArbor 主仓库不能为了看起来完整而提前创建空智能体应用目录。
