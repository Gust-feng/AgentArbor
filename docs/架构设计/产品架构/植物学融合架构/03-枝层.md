# 枝层（Aboveground Growth Coordination）- 地上生长协调

## 定位

枝层表示地上生长中的协调结构。它根据 Growth Plan 拆分任务、分配执行者、维护进度和阻塞报告。

枝层不是常驻事实源，也不是计划裁决者。

## 输入输出

| 项 | 内容 |
| --- | --- |
| 输入 | Growth Plan、Workflow IR、TaskSpec、ConstraintRef、ContextPack |
| 输出 | 任务分配、进度事件、Artifact、约束偏离报告、阻塞报告、Nutrient Request、验证请求 |

## 职责

- 把 Workflow IR 节点转成可执行任务。
- 根据能力、权限和上下文选择 single agent、sub-agent tree、shared team cluster 或 competitive team cluster。
- 收集执行状态、失败证据和产物引用。
- 在发现方向证据、资产适配、外部事实或上下文养料不足时向 Aboveground Center 报告缺口，并通过 Nutrient Request 请求地下中枢供给。

## 禁止事项

- 不修改 Growth Plan。
- 不自行豁免约束。
- 不自建方向探索集群。
- 不把局部产物写入 Soil。
- 不绕过 MessageBus、Router、状态机和 EventLog。
