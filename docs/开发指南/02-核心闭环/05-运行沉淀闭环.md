# 运行沉淀闭环

> 适用范围：说明当前程序性记忆与未来经验沉淀的边界；当前 run 不会自动进入治理或 Global Soil。

## 定位

运行沉淀闭环回答一个核心问题：AgentArbor 完成一次任务后，系统到底收获了什么。

沉淀不是最后写一段总结，也不是把所有输出直接保存为长期资产。当前已落地的是模型主动保存、按需读取并明确引用的路径依赖；未来经验治理链仍不能被当作当前运行行为。

## 基本链路

```text
Run birth：冻结 owner scope + 有界路径依赖目录
  -> 模型可选 MemorySearch / MemoryRead
  -> Ordinary 记录 read/reference 事实
  -> 模型可选 MemoryReference，Ordinary 记录 applied/use 事实
  -> 模型可选 PathDependencySave，PathDependencyFeature 保存方法论
  -> Memory Center 组合展示记忆与引用投影
```

该链路不自动从终态采集任何内容：模型不读取、引用或保存时，不产生相应事实。方法论正文不在 Run birth 全量注入，只有 `MemoryRead` 成功后才进入当前上下文。

## 当前路径依赖

路径依赖由 `PathDependencyFeature` 按稳定 `global`、`spaceId` 或 `workspaceId` owner 保存；它是模型提炼的可复用方法论，不是单次运行档案。模型只可使用当前 Run capability snapshot 授权的 global + 当前 Conversation owner 作用域。

`PathDependencySave` 创建或按 expectedRevision 更新方法论；`MemorySearch` 返回有界候选，`MemoryRead` 返回完整正文和版本，`MemoryReference` 只在已读取精确版本后记录模型明确采用。读取和采用是 Ordinary 的 Run 事实，PathDependencyFeature 不建立平行 runner、运行状态或 read-model。Memory Center 只经公开 facade 组合管理与展示；它可显式选择已登记且未删除的 Space / Workspace，但该管理选择不扩张模型工具的 frozen direct owner 边界。

明确不做：终态自动采集、Dream、原始工具流水回放、向量检索、Path Bias、自动入土或 Governance/Global Soil 回流。历史 `PathMemory`、`Experience Candidate` 既不迁移也不导入。

## 历史经验治理构想（非当前运行）

下列 `PathMemory -> Experience Candidate -> Governance -> Capability Asset / Path Bias -> Global Soil` 是早期长期架构构想，不是当前路径依赖的实施阶段，也不会由 Ordinary run 自动触发。保留它只为解释未来能力名词；历史 `PathMemory` / `Experience Candidate` 是未导入的孤儿，不得据此推断或生成当前路径依赖。

## Capability Asset

Capability Asset 是经过治理后进入 Global Soil 的正式资产。它可以是工作流片段、验证规则、工具适配、提示模板、固定内部 agent 或可脱离子 agent。

晋升要求：

- 有真实运行来源。
- 有可复现输入输出。
- 有验证证据。
- 有权限边界。
- 有适用范围和不适用条件。
- 有版本和退役路径。

## 当前硬规则

- 路径依赖只能由显式 `PathDependencySave` 创建或更新，不能由终态、回复文本或工具流水自动生成。
- MemorySearch 的曝光不等于读取或采用；MemoryRead 记录读取，MemoryReference 才记录明确采用。
- owner、权限和 revision 在 Run 中冻结；更新和删除必须使用 expectedRevision/CAS，不能静默覆盖。
- 不得全量注入方法论正文、跨 Space/Workspace 隐式继承，或用标题关键词推断引用。
- 历史 PathMemory / Experience Candidate 不参与当前运行、迁移或 Governance；Dream、向量、Path Bias 和 Global Soil 仍未出生。
