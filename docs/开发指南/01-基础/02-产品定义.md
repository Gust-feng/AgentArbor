# 产品定义

## 一句话定义

AgentArbor 是目标驱动的智能体 / 智能体应用（AgentApp）孕育与演化平台。它以 `Soil -> Underground Center -> .agentarbor -> Aboveground Center -> Fruits -> Governance -> Soil` 为原生概念树，把用户目标、土壤资产、约束、证据和方向交接成可执行计划，并把真实任务中的有效路径、能力和判断沉淀为受治理的长期资产。

## 用户获得什么

用户提供一个目标或场景，系统应逐步形成：

1. Direction Handoff：地下中枢在 `.agentarbor` 中形成的方向交接包，包含目标、非目标、证据、约束、风险、Soil 引用和 Growth Entry。
2. 目标内核与约束集合：目标、非目标、Constraint / ConstraintRef、验收标准、风险和变更记录。
3. Soil 读取结果：可用固定资产、能力资产、历史运行、治理规则和权限边界。
4. Growth Plan：地上中枢的决策输出，明确选定方向、Workflow IR、运行组织、复用策略和沉淀策略。
5. Aboveground Growth 运行组织：按 Workflow IR 组织执行的协作集群和具体执行个体。
6. Verification 证据：测试、检查、人工确认、失败记录和修复依据。
7. Nutrient Request / Patch 记录：运行中养料请求、养料补充、方向版本和计划修订的原因、证据与版本关系。
8. Run Memory：本次运行后的经验摘要。
9. Path Bias：下一次相似任务可参考但不能强制复刻的路径倾向。
10. Experience Candidate：有复用潜力但尚未进入土壤的候选经验。
11. Capability Asset / Fruit：经过治理后进入土壤的正式能力资产或可脱离果实。
12. 谱系记录：来源目标、生成过程、版本、能力继承、分支和演化记录。

## 核心产品对象

### 智能体应用（AgentApp）

智能体应用是围绕一个目标或场景形成的可运行应用单元。它不是单个提示词，也不是单个智能体文件，而是目标、Agent 集群、能力、工作流、运行工程、测试和文档的组合。

### Direction Handoff

Direction Handoff 是 Underground Center 的输出。它建议采用 `.agentarbor` 方向交接包形态保存目标、非目标、假设、缺失信息、证据索引、约束引用、Soil 引用、可选方向、用户决策记录和 Growth Entry。Direction Handoff 不是长期资产，也不是 Growth Plan。

### Underground Center

Underground Center 是地下中枢。它从用户目标和 Soil 中吸收资产、相似运行、约束和治理规则，向不同方向探索目标，输出版本化 Direction Handoff。Underground Center 不直接制定最终计划，也不直接执行任务。

### Growth Plan

Growth Plan 是 Aboveground Center 的决策输出。Aboveground Center 把 Direction Handoff 中的证据、备选方向和 Path Bias 选择结果转化为执行前计划入口。每个 Growth Plan 必须引用具体 Direction Handoff 版本，并支持基于 Nutrient Patch 的 Growth Plan Revision。

### 约束工程

约束工程让约束从 Soil 到 Underground Center、`.agentarbor`、Aboveground Center、Fruits、Governance 再回到 Soil 的过程中可提取、可传递、可执行、可验证、可沉淀。它区分 hard constraint、soft constraint 和 preference：硬约束可以阻断行动，软约束允许带证据偏离，偏好只能影响 Path Bias 和方案排序。

### Path Bias

Path Bias 是相似任务对历史有效路径的自然倾向。它帮助系统复用上一轮任务开拓出的工作流、能力组合和验证门，但必须允许本次任务根据新目标、新约束和新证据偏离历史路径。

### 能力资产

能力资产是经过评估后可以复用的长期资产。它可以是工具适配器、工作流片段、验证规则、提示词模板、智能体应用模板、智能体角色或完整子智能体。Run Memory 和 Experience Candidate 都不能直接等同能力资产。

### 子 agent 果实

子 agent 果实是能力资产的一种成熟形态。它必须来自真实任务和治理评估，具备清晰输入输出、最小权限、版本、评估证据和退役路径。

### 母体

母体是 AgentArbor 的孕育与治理环境。它提供目标管理、资产土壤、运行时、验证、谱系和导出能力。子 agent 脱离母体时不能默认继承母体的密钥、资产图、历史任务或注册表写权限。

## 价值判断

AgentArbor 的价值不由生成文件数量衡量，而由以下指标衡量：

- 目标能否被持续保留和追踪。
- 执行是否可观察、可暂停、可恢复。
- 结果是否能验证。
- 每次运行是否能形成 Run Memory、Experience Candidate 和 Path Bias。
- 能力是否能被治理后复用。
- 子 agent 是否能在最小权限下脱离母体。
- 失败、重复、过时能力是否能被修剪。
