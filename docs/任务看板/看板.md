# 历史看板

最后更新：2026-05-16

本页是早期 Trellis 任务看板的冻结说明。旧看板曾从 `.trellis/tasks/` 派生当前指针、前置任务和未来方向；这套机制现在不再作为 AgentArbor 的任务源、约束源或续接入口。

## 当前事实源

- `AGENTS.md`：AI 开发硬规则和当前协作边界。
- `docs/架构设计/产品架构/ADR-0022-AgentArbor桌面通用Agent与双运行时架构.md`：长期产品架构事实源。
- `docs/架构设计/产品架构/ADR-0024-桌面基础Agent与基础设施优先路线.md`：当前活跃实现路线。
- `docs/开发指南/`：当前稳定开发口径。
- 用户最新指令：优先打磨默认普通 `agent`；不做可见 deep 入口；不主动改动 deep 后端。

## 当前开发焦点

当前阶段聚焦默认桌面 Agent：

- 输入和连续会话要像普通桌面助手一样稳定可用。
- 模型工具循环、工具可见结果、确认、安全事件、会话持久化和工作台呈现先闭环。
- Skills、Tools、Settings 等入口只展示真实可用能力，不展示占位流程。
- deep / advanced / Underground 相关能力冻结为未来项目，不进入默认首屏、普通会话文案或本轮后端改动。

## 后续计划放置规则

- 稳定产品口径进入 `docs/开发指南/`。
- 长期架构决策进入 `docs/架构设计/`。
- 具体实现边界进入对应代码、测试和必要的任务契约文档。
- `.trellis/tasks/` 只作为历史材料查看，不再新增、启动、续接或刷新当前任务。
