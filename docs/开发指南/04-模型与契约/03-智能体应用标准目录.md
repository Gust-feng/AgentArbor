# 智能体应用标准目录

## 目标

智能体应用标准目录用于承载经过治理后确实需要独立运行的可脱离 agent 或 AgentApp。它必须服务执行、验证、维护和导出，而不是追求表面完整。

## 建议目录

```text
agentapp/
  arbor.json
  README.md
  agents/
  capabilities/
  workflows/
  prompts/
  adapters/
  tests/
  docs/
  lineage/
```

## 目录职责

- `arbor.json`：AgentApp 入口描述。
- `README.md`：人类可读入口。
- `agents/`：AgentApp 内部 agent 定义。
- `capabilities/`：能力声明和依赖。
- `workflows/`：Workflow IR 或平台工作流适配。
- `prompts/`：提示词资产。
- `adapters/`：外部平台、模型或工具适配。
- `tests/`：测试和验收样例。
- `docs/`：AgentApp 自身文档。
- `lineage/`：谱系记录和验证证据。

## 出生规则

这些目录只在智能体应用真实生成且经过治理后创建。AgentArbor 主仓库不能为了看起来完整而提前创建空智能体应用目录。

AgentApp 可以引用生成它的 Plan、Workflow IR、验证证据和治理记录，但不能把 Plan Package 或 `.agentarbor` 目录复制成自身长期事实源。
