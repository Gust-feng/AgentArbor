# 脱离母体边界

## 脱离不是默认结果

子 agent 脱离母体是治理结果，不是生成文件后的默认状态。脱离意味着它要在更小上下文、更少权限、更明确契约下独立承担一类任务。

## 脱离前检查

脱离前必须确认：

- 任务范围稳定。
- 输入输出稳定。
- 权限最小化。
- 不依赖母体内部隐藏状态。
- 不继承母体密钥。
- 不继承母体资产图。
- 不拥有母体注册表写权限。
- 有失败处理和人工接管路径。
- 有版本和撤回机制。

## 脱离包内容

可脱离子 agent 至少需要携带：

- FruitManifest。
- 独立运行入口。
- config.example.yaml。
- schemas。
- tests。
- SECURITY.md。
- RUNBOOK.md。
- lineage.json。
- prompt 或策略。
- 工具和依赖声明。
- 权限声明。
- 输入输出契约。
- 验证样例。
- 运行说明。
- 谱系摘要。
- 兼容平台适配。

建议结构：

```text
<agent-name>/
  fruit.yaml
  README.md
  LICENSE
  config.example.yaml
  bin/
  src/
  prompts/
  schemas/
  tests/
    smoke/
    regression/
  examples/
  docs/
    SECURITY.md
    RUNBOOK.md
  lineage.json
```

导出包不得包含母体密钥、用户隐私数据、Plan Package 正文副本或未脱敏 trace。

## 回流机制

脱离子 agent 的运行结果可以回流到母体，但必须经过导入和验证。母体不能默认信任外部运行结果。
