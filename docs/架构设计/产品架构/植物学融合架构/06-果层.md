# 果层（Fruit）- 交付、复用与脱离

## 职责

果层表示成熟交付物。Fruit 可以是 AgentApp、能力包、工作流包、平台适配输出或可脱离子 agent。

Fruit 不是所有输出的统称。只有经过验证、验收、谱系记录和治理判断的成果，才能被称为果实。

## 果实类型

| 类型 | 说明 |
| --- | --- |
| Delivery Fruit | 面向用户的最终交付物 |
| AgentApp Fruit | 可运行、可验证、可维护的智能体应用 |
| Capability Fruit | 可复用能力包或工作流包 |
| Child Agent Fruit | 可以脱离母体运行的子 agent |
| Adapter Fruit | Codex、OpenCode 或其他平台的适配输出 |

## 脱离母体边界

可脱离子 agent 必须完成：

- 明确输入输出。
- 最小权限。
- 版本和变更记录。
- 评估报告和示例运行。
- 安装、运行和撤回路径。
- 与母体密钥、资产图、历史任务和注册表写权限隔离。

## 与土壤关系

果实可以反哺土壤，但不能自动入土。Fruit 进入 Soil 前仍必须经过 Governance Gate，并明确它是 Capability Asset、参考资料、平台适配输出，还是应归档的交付物。
