# 叶层（Aboveground Growth Execution）- 地上执行个体

## 定位

叶层表示执行具体任务的 agent、工具调用或短期执行单元。它只处理分配给自己的 ContextPack、ConstraintRef、输入和产物要求。

叶层不拥有全局方向，也不拥有长期资产写入权。

## 输入输出

| 项 | 内容 |
| --- | --- |
| 输入 | TaskSpec、ContextPack、ConstraintRef、权限声明、工具清单 |
| 输出 | Artifact、EventLog、执行结果、约束满足或偏离证据、失败证据、验证请求、养料请求建议 |

## 职责

- 执行任务。
- 记录可回放事件。
- 提交产物和证据。
- 明确说明约束满足、偏离或无法判断的原因。
- 发现证据不足时上报，而不是自行猜测补齐。

## 禁止事项

- 不直接修改 Growth Plan。
- 不直接写 Soil。
- 不私下调用其他 agent。
- 不把执行成功当成验证通过。
