# 植物学语义映射

## 总表

| 概念树节点 | AgentArbor 语义 | 主要输出 | 禁止误用 |
| --- | --- | --- | --- |
| Soil | 固定事实、长期资产、治理规则、历史证据和失败模式 | Capability Asset、稳定约束、Path Bias、资料、失败模式 | 不能直接接收未治理临时输出 |
| Underground Center | 需求成形、约束提取、证据探索、方向综合和养料供给 | 方向判断、证据索引、升级条件、方向交接包版本、Nutrient Patch | 不能生成地上执行计划 |
| `.agentarbor` | 地下到地上的方向交接包 | Direction Brief、ConstraintRef、Soil 引用、Growth Entry | 不能成为最终资产库或 Soil 副本 |
| Aboveground Center | 计划化、生长控制、上下文拓扑和计划修订 | Growth Plan、Workflow IR、TaskSpec、Verification Plan | 不能绕过方向交接包 |
| Aboveground Growth | 动态执行、协作、产物提交和验证反馈 | Artifact、执行事件、验证输入 | 不能自行放行结果或修改方向 |
| Fruits | 成熟交付物与候选沉淀 | AgentApp、能力包、子 agent 候选、Run Memory、Experience Candidate | 不能自动入土 |
| Governance | 成熟度、权限、谱系、版本、导出、退役和入土裁决 | 晋升、拒绝、退役、Capability Asset、Path Bias | 不能省略证据和权限边界 |
| Ring Memory | 多次运行的聚合视图 | 趋势、重复失败、可修剪资产线索 | 不能成为新的事实源 |

## 主线

```text
Soil
  -> Underground Center
  -> .agentarbor
  -> Aboveground Center
  -> Aboveground Growth
  -> Fruits
  -> Governance
  -> Soil
```

## 设计约束

- Soil 负责稳定，不负责临时执行。
- Underground Center 负责方向成形，不负责地上执行。
- `.agentarbor` 负责交接，不负责沉淀。
- Aboveground Center 负责计划和修订，不亲自替代所有执行。
- Aboveground Growth 负责运行，不负责资产晋升。
- Verification 负责验证，不负责自我证明。
- Fruits 负责交付和候选沉淀，不默认继承母体权限。
- Governance 负责入土裁决，不创建无证据长期资产。
- Ring Memory 负责观察沉淀，不创建平行事实。
- Path Bias 不能覆盖 hard constraint。
