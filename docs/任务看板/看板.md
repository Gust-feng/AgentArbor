# 历史看板

最后更新：2026-07-12

本页是早期 Trellis 任务看板的冻结说明。旧看板曾从 `.trellis/tasks/` 派生当前指针、前置任务和未来方向；这套机制现在不再作为 AgentArbor 的任务源、约束源或续接入口。

## 当前事实源

- `AGENTS.md`：AI 开发硬规则和当前协作边界。
- `docs/架构设计/产品架构/ADR-0028-AgentArbor统一Workbench与功能模块化单体架构.md`：长期产品架构事实源。
- `docs/开发指南/06-工程实现/11-功能模块边界与组合根.md`：当前工程边界。
- ADR-0024 至 ADR-0027：分别保留 Ordinary 默认、Multi-Agent 内部闭环、Sub-Agent 工具与工具事实链契约。
- `docs/开发指南/`：当前稳定开发口径。
- 用户最新指令：产品收口为单一 Workbench；Ordinary 默认，Multi-Agent 显式，Sub-Agent 是 Ordinary 工具。

## 当前开发焦点

当前阶段先收口事实源、模块依赖和唯一后端 Composition Root，同时保持默认桌面 Agent 行为：

- 输入和连续会话要像普通桌面助手一样稳定可用。
- 模型工具循环、工具可见结果、确认、安全事件、会话持久化和工作台呈现先闭环。
- Skills、Tools、Settings 等入口只展示真实可用能力，不展示占位流程。
- 当前 Agent 集群 beta 侧栏和 `/api/deep/*` 是统一 Workbench 下的过渡实现；不自动升级普通请求，也不能解释为第二个产品。

## 后续计划放置规则

- 稳定产品口径进入 `docs/开发指南/`。
- 长期架构决策进入 `docs/架构设计/`。
- 具体实现边界进入对应代码、测试和必要的任务契约文档。
- `.trellis/tasks/` 只作为历史材料查看，不再新增、启动、续接或刷新当前任务。
