# 植物学语义映射

## 总表

| 树形部位 | AgentArbor 语义 | 主要输出 | 禁止误用 |
| --- | --- | --- | --- |
| Imagination | 用户提示词中的原始想象 | 用户意图、背景、初始约束 | 不能直接进入正式运行 |
| Seed | 经前置成像后的启动种子 | Seed Packet | 不能替代 Growth Plan 或长期资产 |
| Soil | 固定资产、治理规则、历史证据和能力资产 | Capability Asset、规则、资料、失败模式 | 不能直接接收未治理临时输出 |
| Root System | 持续地下探索与吸收系统 | Root Brief 版本 | 不能写成一次性前置调研 |
| Root Crown | 根颈固定核心集群 | 经审计的 Root Brief | 不能成为单点最强 agent |
| Trunk / Core Control | 主干固定核心控制 | Growth Plan、Growth Plan Revision、Workflow IR | 不能跳过 Root Brief 或 Verification |
| Branch | 运行协调结构 | 任务分配、状态流转 | 不能成为常驻角色堆 |
| Leaf | 具体执行单元 | Artifact、执行事件 | 不能自行放行结果 |
| Flower | 验证、评审、成熟度判断 | Verification、Acceptance、治理建议 | 不能伪造证据 |
| Fruit | 成熟交付物或可脱离能力 | AgentApp、能力包、子 agent | 不能无谱系脱离母体 |
| Ring | 多次运行的沉淀视图 | Ring Memory | 不能成为新的事实源 |

## 主线

```text
Imagination
  -> Seed Cluster
  -> Seed Packet
  -> User Approval Gate
Soil
  -> Initial Rooting
  -> Root Brief
  -> Core Control Cluster
  -> Growth Plan
  -> Workflow IR
  -> Branch / Leaf Runtime
  -> Flower Verification
  -> Root Callback / Re-rooting
  -> Run Memory / Path Bias
  -> Fruit or Soil Governance
```

## 设计约束

- 土壤负责稳定，不负责临时执行。
- 种子层负责启动前成像，不负责正式执行。
- 根系负责持续探索，不负责最终裁决。
- 主干固定核心负责综合和修订计划，不负责亲自执行。
- 枝叶负责运行，不负责资产晋升。
- 花负责验证，不负责自我证明。
- 果负责交付和脱离，不默认继承母体权限。
- 年轮负责观察沉淀，不创建平行事实。
