# 工作台界面

## 界面目标

未来工作台不是营销首页，而是面向真实开发和治理的操作界面。它应该让用户清楚看到 Soil、Underground Center、`.agentarbor`、Aboveground Center、Aboveground Growth、Fruits、Governance、约束、验证证据、Run Memory、Path Bias 和能力生长状态。

## 主要视图

### 土壤视图

显示长期事实、能力资产、治理规则、历史证据、失败模式、Path Bias 和稳定约束。

### 地下中枢视图

显示用户目标、非目标、缺失信息、约束提取、证据探索、方向综合、用户升级确认和养料供给状态。

### 方向交接包视图

显示 `.agentarbor` 中的 Direction Brief、ConstraintRef、Soil 引用、证据索引、未决问题、升级规则和 Growth Entry。

### 地上中枢视图

显示 Growth Plan、Workflow IR、Context Topology、任务切片、运行组织形态、验证门和计划修订记录。

### 执行视图

显示当前 Workflow IR 的任务图、运行状态、工具调用、文件变化、失败原因和恢复点。

### 验证视图

显示测试结果、检查清单、人工确认项、约束满足情况、失败证据和修复建议。

### 果实视图

显示交付物、AgentApp、能力包、可脱离子 agent 候选、Run Memory、Experience Candidate、复用条件、不适用条件、失败模式和权限结论。

### 谱系与治理视图

显示候选果实到 Capability Asset、Path Bias、导出包或退役记录之间的来源关系、评估结果、版本、权限要求和治理结论。

## 界面边界

UI 不能直接绕过权限层访问本地资产，不能直接写长期能力注册表，也不能把平台适配格式展示成 AgentArbor 原生事实。
