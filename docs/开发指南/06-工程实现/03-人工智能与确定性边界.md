# 人工智能与确定性边界

## 人工智能负责什么

AI 可以参与：

- Seed Cluster 前置成像。
- 目标澄清和需求结构化。
- 方案生成。
- Root System 探索建议。
- Core Control Cluster 计划建议。
- Branch / Leaf 组织建议。
- 工作流草案。
- Path Bias 候选建议。
- 提示词和文档生成。
- 代码或配置草案。
- 失败原因分析。
- 能力候选建议。
- Root Callback 和 Growth Plan Revision 建议。

## 系统负责什么

确定性系统必须负责：

- 数据结构校验。
- Seed Packet 状态与用户确认门。
- Root Brief Versioning。
- Growth Plan Revision 版本关系。
- 权限判断。
- 状态转换。
- 文件写入边界。
- 命令执行边界。
- 测试运行。
- 事件记录。
- Run Memory 写入规则。
- Experience Candidate 晋升规则。
- Path Bias 写入和读取规则。
- Root Callback 写入和读取规则。
- 谱系记录。
- 版本管理。
- 导出打包。

## 核心原则

LLM 可以提出内容，不能单独拥有最终事实。任何长期资产、子 agent 脱离、权限扩大、导出和删除行为，都必须经过确定性检查和必要的人类确认。
