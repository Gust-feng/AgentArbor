# 阶段验收边界

## 文档阶段验收

当前文档阶段完成标准：

- 产品定位清楚：AgentArbor 是桌面通用 Agent。
- 当前事实源是 ADR-0028，而不是旧原生概念树或双运行时并列产品结构。
- 开发指南、历史看板、研究资料和架构设计边界清楚。
- `.agentarbor` 已降级为 Plan Package 的实现/存储形态，不再作为独立产品节点。
- Task Soil / Global Soil 双层土壤已经明确。
- 单一 Workbench、Ordinary 默认、Multi-Agent 显式功能和 Sub-Agent 工具定位已经明确。
- 功能自有业务状态、事件、仓储和 read-model，共享层只提供中性能力。
- 唯一 Composition Root 和禁止 universal Run runtime 的边界已经明确。
- 四层权限模型已经明确。
- Main Canvas 与 Observation Panel 的解释分工已经明确。
- MVP 禁止递归派生 child agent。
- Fruits 和 Global Soil 之间存在明确 Governance Pipeline。
- 索引全部指向真实文件。

## 实现阶段验收

后续默认 agent 打磨的最小验收标准：

- 能从 Desktop Shell 输入自然语言任务。
- 能持续对话，并把最近可见对话作为模型上下文传递。
- 能通过中性 `AgentLoop` 和 Pi AgentHarness/Session 完成 Ordinary 模型工具循环；Deep 可独立使用 `AgentTurnRuntime`。
- 能按本轮冻结策略处理命令和高影响工具确认；普通读取与低风险工作区编辑不被无意义确认反复打断。
- 能持久化会话、运行、事件和命令确认请求的运行投影。
- 能展示普通回答、工具引用、待确认事项、错误和结果摘要。
- 能执行至少一个样例任务。
- 能记录运行事件和必要谱系。
- 能运行验证并给出通过或失败证据。
- 普通模型正文、工具结果、错误信息、文件正文、stdout/stderr 和开发上下文不得被脱敏或安全投影吞掉；持久化记录可为体积和结构保存摘要，但不能替代模型可继续使用的真实工具结果。
- 能在主工作区展示结果级解释。
- 能在详情或诊断中展示 agent 过程级运行投影。

## 不合格信号

出现以下情况，说明方向偏离：

- 只有聊天回答，没有工具循环、确认、运行事件、持久化或结果展示。
- 只生成 prompt 或角色文件。
- 只有文档，没有可执行规格。
- 只有运行，没有验证。
- 只有生成，没有谱系。
- 只有平台适配，没有 AgentArbor 原生模型。
- Multi-Agent 被恢复为第二个产品，或普通请求被工程规则自动升级到 Multi-Agent / Underground。
- `.agentarbor` 被恢复成独立产品节点或最终资产仓库。
- Fruit 绕过 Governance Pipeline 进入 Global Soil。
- 子 agent 能绕过权限和治理直接脱离母体。
- 工程边界替 agent 判断目标理解、候选排序、是否继续探索或方向综合。
