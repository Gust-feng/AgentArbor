# 最小实现边界

## 第一阶段目标

第一阶段应证明 AgentArbor 可以从用户 Imagination 孕育一个最小 AgentApp，并完成验证和谱系记录。
同时，第一阶段必须证明系统不是一次性生成器：运行结束后要形成 Run Memory，并让下一次相似任务能读取 Path Bias。

## 最小路径

```text
输入 Imagination
  -> Seed Cluster 形成 Seed Packet
  -> User Approval Gate
  -> Root System 形成 Root Brief v1
  -> Core Control Cluster 形成 Growth Plan v1
  -> 生成 Workflow IR
  -> 生成最小工程目录
  -> 执行样例任务
  -> 运行验证
  -> Root Callback / Growth Plan Revision
  -> 写入 Run Memory
  -> 生成 Experience Candidate
  -> 形成 Path Bias
  -> 写入谱系记录
```

## 第一阶段骨架

第一阶段不要从“写很多智能体”开始。必须先让消息、状态、注册、产物和事件跑通。

最小实现顺序：

```text
1. ArborMessage
2. SeedPacket
3. AgentManifest
4. TaskState
5. RootBrief
6. GrowthPlan
7. RootCallback
8. GrowthPlanRevision
9. BaseAgent
10. InMemoryMessageBus
11. InMemoryAgentRegistry
12. InMemoryEventLog
13. InMemoryArtifactStore
14. SimpleRouter
15. 最小 demo
```

最小 demo 必须证明：

```text
用户目标
  -> imagination.received
  -> SeedAnalyzer 生成 seed_packet.completed
  -> user_approval.received
  -> RootSystemExplorer 生成 root_brief.completed
  -> CorePlanner 生成 growth_plan.completed
  -> Workflow IR 生成 task.created
  -> Router 根据 requiredCapabilities 分配 WorkerAgent
  -> WorkerAgent 生成 artifact.produced
  -> Verification 运行
  -> 可选 root_callback.requested / growth_plan.revised
  -> 生成 RunMemory
  -> 生成 ExperienceCandidate
  -> 生成 PathBias
  -> EventLog 可回放全过程
```

## 暂不做

第一阶段不做：

- A2A Adapter。
- MCP Adapter。
- AG-UI Adapter。
- 完整模型调用。
- 完整插件市场。
- 企业多租户。
- 大规模 agent 自治网络。
- 完全自动自我修改。
- 无人值守高风险命令执行。
- 数据库持久化。
- 复杂可视化编排器。

## 必须保留的扩展口

即使第一阶段很小，也必须保留：

- 内部消息契约。
- 目标状态机。
- Workflow IR。
- AgentManifest。
- SeedPacket。
- RootBrief。
- GrowthPlan。
- RootCallback。
- GrowthPlanRevision。
- RunMemory。
- ExperienceCandidate。
- PathBias。
- MessageBus。
- AgentRegistry。
- ArtifactStore。
- EventLog。
- 权限声明。
- 验证门。
- 谱系记录。
- 平台适配层。
- 能力晋升的治理门。

## 最小验收

第一阶段通过条件：

- 用户目标能进入系统。
- 至少两个内部智能体参与。
- 智能体只能通过 MessageBus 协作，不能绕过总线互相调用。
- 任务状态发生真实流转。
- 至少产生一个 Artifact。
- 至少写入完整 EventLog。
- 至少执行一次 Verification。
- Root Callback 的触发条件、消息和结果结构已经保留，哪怕最小 demo 只走不触发路径。
- 至少写入一次 RunMemory。
- 至少生成一个 ExperienceCandidate。
- 至少形成一个可供下一次相似任务读取的 PathBias。
- EventLog 能打印或展示完整链路。
