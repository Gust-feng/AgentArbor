# 地下养料供给与方向修订

## 定位

Nutrient Request 是 Aboveground Execution Runtime 发现 Plan 信息不足时回到 Underground Cognitive Runtime 的机制。它保护方向智能和执行智能的边界：地上可以报告缺口、阻塞和当前假设，但不能自建地下探索集群，也不能用猜测补齐 Plan。

本章仅在 Plan / Aboveground 模块真实出生后适用，不是当前 Ordinary 或 Multi-Agent 请求的默认流程。

Underground 收到 Nutrient Request 后补充探索，输出 Nutrient Patch 或 Plan vNext。Aboveground 基于新版本继续、回退、分叉或停止。

## 养料类型

| 养料类型 | 地上缺口 | 地下输出 |
| --- | --- | --- |
| 证据养料 | 方向依据、验证依据或假设依据不足 | EvidenceRef、Assumption Verdict |
| Global Soil 资产养料 | 需要复用能力、历史路径、失败模式或治理规则 | SoilRef、Capability Asset Ref、Path Bias Ref |
| 约束养料 | 权限、成本、安全、验收或治理边界不清 | ConstraintRef、CandidateConstraintRef、冲突说明 |
| 外部事实养料 | 需要当前事实、外部标准、平台能力或环境边界 | FactRef、来源、时间戳、可信度 |
| 上下文养料 | 执行节点缺材料、上下文切片不够或引用不清 | Context Supplement、适用范围 |
| 能力线索养料 | 不确定是否已有能力可用或需要新能力 | Capability Hint、适用条件、不适用条件 |

## 供给模式

| 模式 | 触发场景 | 输出 |
| --- | --- | --- |
| 初始方向供给 | 用户任务进入地下运行时 | Plan v1 |
| 局部养料补充 | 局部任务材料不足、局部失败、局部验证不清 | Nutrient Patch |
| 方向补充 | Plan 前提需要补证据或补约束 | Plan Supplement 或 Plan vNext |
| 方向再成形 | 方向前提被证伪、目标变化、Path Bias 失效 | Plan vNext 和执行重估建议 |

## 请求者

- Aboveground Execution Runtime。
- Execution agent / tool action。
- Verification / Acceptance。
- Governance Pipeline。

请求者只能描述缺口、用途、阻塞等级、当前假设和需要支撑的节点，不能直接指定 Underground 必须采用的结论。

## 触发原因

- 证据不足。
- 执行反复失败，需要判断失败是执行问题还是方向养料不足。
- 验证不通过，且缺少可判定证据。
- Path Bias 失效。
- Global Soil 资产不适用或适用条件不清。
- 用户修改目标。
- 权限、成本或不可逆动作前提不成立。
- Plan 的关键假设被证伪。
- 治理发现谱系、权限或证据不足。

## 养料请求流程

```text
Aboveground 发现养料缺口
  -> Nutrient Request
  -> Underground 判断需要局部补充、方向补充或方向再成形
  -> 补齐证据、约束、用户确认、Global Soil 引用、外部事实或能力线索
  -> 生成 Nutrient Patch 或 Plan vNext
  -> Aboveground 消化养料并判断是否继续、回退、分叉或停止
```

## 版本规则

- Plan 必须版本化。
- Nutrient Request 和 Nutrient Patch 必须关联具体 Plan、执行节点、验证门或治理记录。
- Plan vNext 必须说明来源 Plan、修订原因、影响范围、继续、回退、分叉或停止建议。
- 如果无需补充养料，也必须记录证据和判断理由。
- `.agentarbor` 如作为存储目录出现，只保存 Plan Package 版本，不复制 Global Soil 资产正文。

## 禁止事项

- 不把 Underground 写成启动前一次性调研。
- 不用过期 Plan 掩盖新证据。
- 不让 Aboveground 自行修订方向判断。
- 不让 Aboveground 自建方向探索集群替代地下养料供给。
- 不用 Nutrient Request 替代 Verification。
- 不把方向再成形当作普通局部养料补充。
