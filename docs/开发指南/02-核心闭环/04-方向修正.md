# 方向修正

## 保留什么

AgentArbor 保留这些产品主张：

- 从自然语言目标或场景启动。
- 生成完整 AgentApp，而不是零散文件。
- 重视 agent 分工、工具、工作流、提示词、测试和文档。
- 让非专业用户也能把场景转化为可运行智能体应用。

## 修正什么

需要修正的是重心：

- 从“应用生成器”修正为“Agent / AgentApp 孕育与演化平台”。
- 从“项目脚手架”修正为“目标、执行、验证、谱系和能力治理闭环”。
- 从“生成 agent 文件”修正为“治理成熟能力并在必要时导出 agent”。
- 从“适配某个平台”修正为“平台适配服务于 AgentArbor 原生语义”。

## 当前写作口径

开发指南只采用稳定口径：

```text
Soil
  + Underground Center 方向成形和养料供给
  + .agentarbor 方向交接

  + Fruits 形成交付物和候选沉淀
  + Governance 裁决入土、导出和退役
  + Run Memory / Path Bias
  + 谱系治理和能力果实
```
