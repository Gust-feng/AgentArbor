# 总原则

## 一句话原则

普通 Agent 的核心是一个由模型驱动的工具循环；工程只负责装配世界、暴露边界、执行工具、记录事实和保护约束，不替模型思考。

## 根目标

默认普通 Agent 必须成为 AgentArbor 后续所有长期能力的稳定主干：

- 当前默认产品先靠它完成连续会话、工具调用、确认、安全投影、持久化和结果展示。
- 后续多 Agent、deep 和长期能力建设复用它已经稳定的运行方式与边界。
- 普通路径不能为了兼容未来而提前做重。

## 主干判断标准

每次涉及普通 Agent 主干的改动，都必须先判断：

1. 这次改动是否让默认普通 Agent 更像一个清晰的一等 Agent。
2. 这次改动是否强化了单一主循环，而不是制造第二套运行语义。
3. 这次改动是否让 AgentDefinition、工具可见性、执行边界或后端事实源更清楚。
4. 这次改动是否减少了默认用户视图噪音。
5. 这次改动是否继续保持命名朴素准确。

只要这五个问题里有明显答不上的项，就不算朝正确方向推进。
