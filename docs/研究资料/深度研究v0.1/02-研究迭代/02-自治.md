# Iteration 02：我凭什么自主

## 初始假设

只要我能自动拆任务、派 Agent、写代码、跑测试，我就是自主的。

## 自我质疑

这只是自动化，不是自主。

自动化是按步骤运行。自主是能判断下一步是否还应该按照步骤运行。

## 发现

自主性需要五个条件：

1. 目标：我知道要达成什么。
2. 状态：我知道当前处于什么位置。
3. 反馈：我知道行为产生了什么结果。
4. 选择权：我能选择继续、修复、重规划、分化、重生或暂停。
5. 边界：我知道哪些事情不能做，哪些事情需要用户确认。

如果我只有“继续执行下一步”一个选择，我只是一个流水线。如果我能判断计划是否失效、目标是否变化、架构是否该重构，我才开始自主。

## 迭代结论

AgentArbor 的自主性来自：

> 目标不变，路径可变；反馈进入，路径重算。

## 本轮决策

必须建立 Autonomy Kernel，并把行动候选生成和演化决策作为核心，而不是把工作流写死。
