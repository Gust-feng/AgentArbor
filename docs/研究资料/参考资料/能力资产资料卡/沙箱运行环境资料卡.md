# 沙箱运行环境资料卡

## 1. 目标

AgentArbor 需要把代码生成、环境构建、运行和测试放入受控环境。

沙箱不等于语言运行时：

```text
Sandbox = 隔离空间
Runtime = 语言和依赖
Runner = 执行 AgentApp 的控制器
```

## 2. 第一版优先资产

### runtime.cubesandbox

```text
类别：Runtime
来源：TencentCloud CubeSandbox
接口：E2B-compatible sandbox
优先级：P0
风险：Medium
来源链接：https://github.com/TencentCloud/CubeSandbox
当前动作：实现 CubeSandboxProvider
```

AgentArbor 抽象建议：

* 作为高隔离沙箱后端候选。
* 不作为第一版唯一强依赖。
* 接入时通过 `SandboxProvider` 抽象，保留切换 Docker / E2B 的能力。

待核验：

* 部署前置条件。
* 模板镜像机制。
* 文件上传和产物导出 API。
* 网络策略和密钥注入方式。
* 与 E2B SDK 的兼容边界。

### runtime.workspace_manager

```text
类别：Runtime
来源：AgentArbor
接口：internal service
优先级：P0
风险：Medium
当前动作：实现 IWorkspaceManager
```

AgentArbor 抽象建议：

* 负责创建临时工作区。
* 负责导入 AgentApp、仓库、样例任务和资产快照。
* 负责限制宿主路径暴露。
* 负责回收工作区。

### runtime.command_runner

```text
类别：Runtime
来源：AgentArbor
接口：internal service
优先级：P0
风险：High
当前动作：实现 ICommandRunner + audit log
```

AgentArbor 抽象建议：

* 所有命令默认在沙箱中执行。
* 命令执行必须有 timeout、cwd、env allowlist、输出大小限制和审计日志。
* 不允许 Agent 直接执行宿主机命令。

### runtime.template.node

```text
类别：SandboxTemplate
来源：AgentArbor
接口：sandbox template
优先级：P0
风险：Medium
来源链接：https://vitest.dev/
```

## 3. 环境规划原则

Agent 可以规划环境，但不能直接安装环境。

正确流程：

```text
Environment Planner
  -> runtime.yaml
  -> build-recipe.yaml
  -> test-recipe.yaml
  -> Policy Validator
  -> Sandbox Builder
  -> Runner
  -> ValidationResult
```

## 4. 底线

* 不做一个装满所有语言的超级镜像。
* 不在宿主机安装 AgentApp 依赖。
* 不允许随机安装脚本默认执行。
* 没有可用 Runtime Asset 时，进入 Suspend 或 EnvironmentProposal。
