# 果层（Fruits）- 交付与候选沉淀

## 定位

果层保存一次运行形成的交付物和候选沉淀。Fruit 可以是 AgentApp、能力包、可脱离子 agent、运行报告、工作流片段、验证规则或经验候选。

Fruit 不是 Soil。它只有经过 Governance 后，才可能以明确类型回流 Soil。

## 果实类型

| 类型 | 说明 | 入土前要求 |
| --- | --- | --- |
| Delivery Fruit | 用户交付物或 AgentApp | 验收通过、谱系完整 |
| Capability Fruit | 可复用能力、工具或工作流片段 | 输入输出契约、验证记录、权限边界 |
| Agent Fruit | 可脱离子 agent | 最小权限、安装测试、运行示例、退役路径 |
| Learning Fruit | Run Memory、Experience Candidate、Path Bias 来源 | 证据来源、适用条件、不适用条件 |

## 治理要求

- 有真实任务来源。
- 有 Direction Handoff、Growth Plan、Workflow IR 和验证记录引用。
- 有权限、版本、适用范围和退役路径。
- 有入土、拒绝、导出或归档结论。

## 禁止事项

- 不把 Fruit 自动写入 Soil。
- 不让子 agent 默认继承母体权限、密钥、资产图或注册表写权限。
- 不把一次成功直接当成 Capability Asset。
