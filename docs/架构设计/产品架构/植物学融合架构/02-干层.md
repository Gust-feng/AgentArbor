# 干层（Aboveground Center）- 地上中枢

## 定位

干层在 AgentArbor 中表示 Aboveground Center。它承接 `.agentarbor` 方向交接包，制定 Growth Plan，并把计划转化为 Workflow IR、上下文拓扑、执行组织和验证门。

地上中枢是低自由度固定核心，用来抵抗单点计划失败和局部最优。

## 组成

| 职责 | 说明 |
| --- | --- |
| Growth Planner | 选择方向、运行组织和复用策略 |
| Plan Critic | 反审查计划、约束冲突和证据缺口 |
| Risk Governor | 检查权限、成本、安全和不可逆动作 |
| Context Topology Builder | 分配共享上下文、父子裁剪上下文和 ContextPack |
| Revision Controller | 根据 Nutrient Patch、验证和治理信号修订计划 |

## Growth Plan 必须包含

- Direction Handoff 版本引用。
- 选定方向和拒绝其他方向的理由。
- Path Bias 采用、调整或拒绝决定。
- Workflow IR。
- 运行组织形态。
- ConstraintRef 分发。
- 复用策略、沉淀策略和验证门。
- Nutrient Request 触发条件。

## 修订规则

当 Underground Center 输出 Nutrient Patch 或新的 Direction Handoff 版本，Aboveground Center 必须判断：

- 是否继续当前计划。
- 是否回退到上一计划。
- 是否分叉为新运行路径。
- 是否停止任务。

Revision 必须记录原因、影响范围、变更任务、引用的 Nutrient Patch 或 Direction Handoff 版本和最终决策。

## 禁止事项

- 不绕过 Direction Handoff 直接生成计划。
- 不用 Path Bias 覆盖 hard constraint。
- 不让地上执行组织自行修改 Growth Plan。
- 不自建方向探索集群替代地下中枢的养料供给。
- 不把单个最强模型当成完整地上中枢。
