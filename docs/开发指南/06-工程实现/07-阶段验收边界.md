# 阶段验收边界

## 文档阶段验收

当前文档阶段完成标准：

- 产品定位清楚。
- 原生概念树已成为活跃文档事实源。
- 开发指南、任务看板、研究资料和架构设计边界清楚。
- `.agentarbor` 被定义为方向交接包，不被写成最终资产仓库。
- Fruits 和 Soil 之间存在明确 Governance 门。
- 索引全部指向真实文件。

## 实现阶段验收

未来进入代码实现后，最小验收标准：

- 能输入自然语言目标。
- 能形成 Direction Handoff。
- 能读写 `.agentarbor` 方向交接包。
- 能生成 Growth Plan。
- 能生成 Workflow IR。
- 能生成可运行最小工程。
- 能执行至少一个样例任务。
- 能记录事件和谱系。
- 能运行验证并给出通过或失败证据。
- 能阻止未验证果实直接进入 Soil。

## 不合格信号

出现以下情况，说明方向偏离：

- 只生成 prompt 或角色文件。
- 只有文档，没有可执行规格。
- 只有运行，没有验证。
- 只有生成，没有谱系。
- 只有平台适配，没有 AgentArbor 原生模型。
- `.agentarbor` 被当作最终资产仓库。
- Fruit 绕过 Governance 进入 Soil。
- 子 agent 能绕过权限和治理直接脱离母体。
