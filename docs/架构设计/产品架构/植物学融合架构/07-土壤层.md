# 土壤层（Soil）- 固定资产与治理层

## 职责

土壤层保存 AgentArbor 可以长期依赖的固定资产、治理规则、历史证据和能力资产。它不是临时运行目录，也不是所有输出的堆放处。

Seed Packet 通过 User Approval Gate 后才种入 Soil。Root System 从 Soil 中吸收资产和证据，但不能绕过治理规则读取或修改土壤。

## 可保存内容

- Capability Asset。
- 经治理的工作流片段。
- 经验证的工具、模型、MCP、插件和外部服务适配。
- 验证规则和评分规则。
- 稳定偏好、约束和权限策略。
- 经确认的失败模式。
- 可检索研究资料和架构资料。
- Fruit 的版本、谱系和退役记录。

## 不直接保存内容

- 未验证聊天内容。
- 临时任务中间文本。
- 单次运行原始流水。
- 未归因经验总结。
- 未通过 User Approval Gate 的 Seed Packet。
- 没有权限边界的 agent 文件。
- 平台适配层的偶然格式。

## 入土流程

```text
EventLog / Artifact / Verification
  -> Run Memory
  -> Experience Candidate
  -> Governance Gate
  -> Capability Asset / Fruit Record
  -> Soil
```

## 治理字段

进入土壤的资产必须记录：

- 来源。
- 输入输出契约。
- 适用范围。
- 不适用条件。
- 验证证据。
- 权限边界。
- 版本。
- 风险。
- 维护责任。
- 退役条件。

## 与年轮关系

Ring Memory 可以观察土壤中的资产如何随运行增长、修剪或退役，但 Ring Memory 不写入新事实。事实源仍是 EventLog、Run Memory、Experience Candidate 和 Governance 记录。
