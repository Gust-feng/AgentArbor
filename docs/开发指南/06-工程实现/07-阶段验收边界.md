# 阶段验收边界

## 文档阶段验收

当前文档阶段完成标准：

- 产品定位清楚：AgentArbor 是桌面通用 Agent。
- 当前事实源是 ADR-0022，而不是旧原生概念树。
- 开发指南、任务看板、研究资料和架构设计边界清楚。
- `.agentarbor` 已降级为 Plan Package 的实现/存储形态，不再作为独立产品节点。
- Task Soil / Global Soil 双层土壤已经明确。
- Shared Agent Kernel + Two Product Runtimes 已经明确。
- 四层权限模型已经明确。
- Main Canvas 与 Observation Panel 的解释分工已经明确。
- MVP 禁止递归派生 child agent。
- Fruits 和 Global Soil 之间存在明确 Governance Pipeline。
- 索引全部指向真实文件。

## 实现阶段验收

未来进入代码实现后，最小验收标准：

- 能从 Desktop Shell 输入自然语言任务。
- 能形成 Task Soil。
- 能通过 Underground Cognitive Runtime 形成 approved Plan。
- 无 `AgentTurnRuntime` 不会 approved。
- 能持久化或内存保存 Plan Package。
- 能由 Aboveground Execution Runtime 消费 Plan。
- 能生成 Workflow IR 或等价执行步骤。
- 能执行至少一个样例任务。
- 能记录事件和谱系。
- 能运行验证并给出通过或失败证据。
- 能阻止未验证果实直接进入 Global Soil。
- 能在 Main Canvas 展示结果级解释。
- 能在 Observation Panel 展示 agent 过程级安全投影。

## 不合格信号

出现以下情况，说明方向偏离：

- 只有聊天回答，没有 Task Soil / Plan / Artifact。
- 只生成 prompt 或角色文件。
- 只有文档，没有可执行规格。
- 只有运行，没有验证。
- 只有生成，没有谱系。
- 只有平台适配，没有 AgentArbor 原生模型。
- `.agentarbor` 被恢复成独立产品节点或最终资产仓库。
- Fruit 绕过 Governance Pipeline 进入 Global Soil。
- 子 agent 能绕过权限和治理直接脱离母体。
- 工程边界替 agent 判断目标理解、候选排序、是否继续探索或方向综合。
