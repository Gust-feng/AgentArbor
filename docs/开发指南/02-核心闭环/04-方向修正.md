# 方向修正

## 保留什么

AgentArbor 保留这些产品主张：

- 从自然语言任务、文件、项目或网页上下文启动。
- 重视 agent 分工、工具、工作流、提示词、测试和文档。
- 让用户把模糊任务转化为可监督、可执行、可交付的工作流。
- 让每次运行形成可复用经验候选，而不是一次性回答。

## 修正什么

需要修正的是重心：

- 从“Agent / AgentApp 生成器”修正为“桌面通用 Agent”。
- 从“项目脚手架”修正为“任务成形、Plan、执行、验证、谱系和治理闭环”。
- 从“生成 agent 文件”修正为“治理成熟能力并在必要时导出 agent”。
- 从“地下集群本身”修正为“Desktop Shell 背后的地下认知内核”。
- 从“适配某个平台”修正为“平台适配服务于 AgentArbor 原生语义”。

## 当前写作口径

开发指南只采用稳定口径：

```text
Desktop Shell
  + Task Soil 承接任务和工作区上下文
  + Underground Cognitive Runtime 负责目标成形、child 派生、父层综合和 Plan
  + Plan 承接地下到地上的交接
  + Aboveground Execution Runtime 执行和验证
  + Fruits 形成交付物和候选沉淀
  + Governance Pipeline 裁决入土、导出和退役
  + Run Memory / Experience Candidate / Path Bias
  + Global Soil 保存治理后的长期事实和能力
```

旧的 `.agentarbor` 方向交接包口径统一解释为 Plan Package 的实现/存储形态。旧的 Growth Plan 口径统一收缩为 Aboveground 从 Plan 派生的执行计划，不再作为产品主线上的独立节点。
