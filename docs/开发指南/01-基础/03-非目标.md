# 非目标

## 不是聊天机器人

AgentArbor 不以多轮聊天体验作为核心产品定义。聊天可以是入口，但不能替代目标内核、工作流、验证、谱系和能力治理。

## 不是 prompt 仓库

Prompt 可以成为能力资产的一部分，但 AgentArbor 不等同于提示词集合。任何提示词进入长期资产前，都必须有用途、输入输出、适用范围、版本、验证方式和维护策略。

## 不是一次性脚手架

从自然语言生成工程目录只是入口能力。系统必须继续管理执行、验证、谱系、复用和演化，否则它只是项目模板生成器。

## 不是单个平台配置仓库

Codex、OpenCode、Agent Skills、MCP 或其他平台格式都属于适配层。AgentArbor 可以导入、生成或同步这些格式，但不能让它们反向定义 AgentArbor 的原生产品模型。

## 不是无边界自治系统

AgentArbor 不追求无约束自我修改。当前默认桌面开发 agent 的运行重点是能力闭环而不是安全优先；命令执行需要确认，其他普通工作区文件读写、删除、网络访问、MCP 工具调用和上下文使用不默认逐次确认。长期资产写入和 deep / 多 agent 治理边界以后续明确契约为准。

## 不是资料堆

研究报告、架构资料和未来态资料有价值，但不能混进当前开发入口。开发指南只保存稳定结论；资料库保存思想来源和可追溯输入。
