# 资产管理

## 定位

资产管理负责让 Experience Candidate 在治理后成为 Capability Asset，并在过期、失败或被替代时完成修剪和退役。Direction Handoff、Growth Plan、Run Memory、Nutrient Request 和 Nutrient Patch 记录可以作为证据来源，但不能直接等同于长期资产。

## 资产类型

| 类型 | 说明 |
| --- | --- |
| Capability Asset | 经治理的能力、工具、工作流片段、验证规则或 agent |
| Path Bias | 对下一次相似任务的路径倾向 |
| Governance Rule | 稳定治理规则 |
| Verification Rule | 可复用验证规则 |
| Fruit Record | 果实版本、谱系和退役记录 |

## 晋升链

```text
Run Memory
  -> Experience Candidate
  -> Governance Review
  -> Capability Asset / Path Bias / Rule
  -> Soil
```

## 资产必须包含

- 来源目标、Direction Handoff、Growth Plan 和 Workflow IR。
- 输入输出契约。
- 权限边界。
- 适用范围和不适用条件。
- 验证记录。
- 版本。
- 维护责任。
- 退役路径。

## 与土壤关系

土壤只保存通过治理门的正式资产。Run Memory、Experience Candidate、Direction Handoff、Growth Plan、Nutrient Request 和 Nutrient Patch 可以被检索和评审，但不能直接作为土壤固定资产使用。

## 禁止事项

- 不把候选经验当正式资产。
- 不让 Fruit 自动入土。
- 不让可脱离子 agent 继承母体密钥、资产图或注册表写权限。
- 不让平台适配文件成为 AgentArbor 原生事实源。
