# 运行沉淀闭环

> 适用范围：需要候选经验沉淀时的长期闭环；当前 run 不会自动进入治理或 Global Soil。

## 定位

运行沉淀闭环回答一个核心问题：AgentArbor 完成一次任务后，系统到底收获了什么。

沉淀不是最后写一段总结，也不是把所有输出直接保存为长期资产。沉淀必须从 owning feature 的真实运行事实开始，逐级形成 PathMemory、Experience Candidate、Path Bias 和 Capability Asset。

## 基本链路

```text
Ordinary stable terminal facts / 未来其他 feature terminal facts
  -> PathMemory
  -> Experience Candidate
  -> Governance Pipeline
  -> Capability Asset / Path Bias / Retire
  -> Global Soil / Ring Memory
```

当前第一阶段只实现 `Ordinary stable terminal facts -> PathMemory`，后续步骤不是每次运行的同步必经链路。

## PathMemory

PathMemory 是单次运行后的结构化路径档案。它由 owning feature 在运行事实稳定后自动采集，必须来自真实运行证据，不能来自事后想象。

最小内容：

- 来源 feature、run、conversation、turn 和来源版本。
- 用户本轮请求、Task Soil 上下文引用和冻结作用域。
- 实际发生的工具事实、顺序和父子关系。
- completed、failed、blocked 或 cancelled 终态。
- 与终态分离的验证状态和证据引用。
- schema 版本、采集时间和删除边界。

PathMemory 不复制完整会话、assistant 回答、工具 input/output 或附件字节，也不在采集时生成成功模式、失败模式、偏离原因和复用建议。它是长期记忆系统的客观来源层，不等于治理后的长期知识。

## Experience Candidate

Experience Candidate 是从 PathMemory 中提取出的可复用经验候选。

它必须回答：

- 哪类目标可复用。
- 复用前需要满足哪些前提。
- 哪些步骤、能力、验证门值得保留。
- 哪些失败模式必须避免。
- 哪些场景不能复用。
- 置信度来自什么证据。

Experience Candidate 不能直接进入 Global Soil。它需要经过验证、去重、适用范围确认和 Governance Pipeline。

## Path Bias

Path Bias 是 Experience Candidate 对下一次相似任务的路径牵引。它不强制复刻历史路径，而是在后续检索契约中让 Agent 优先看见已验证路径，并自行判断是否采用。

Path Bias 必须保留偏离空间：当新的目标、约束、权限、上下文或验证要求与历史路径冲突时，Agent 必须允许选择新路径；未来语义分析可以把有证据的偏离原因形成新的 Experience Candidate，但不能回写原 PathMemory。

## Capability Asset

Capability Asset 是经过治理后进入 Global Soil 的正式资产。它可以是工作流片段、验证规则、工具适配、提示模板、固定内部 agent 或可脱离子 agent。

晋升要求：

- 有真实运行来源。
- 有可复现输入输出。
- 有验证证据。
- 有权限边界。
- 有适用范围和不适用条件。
- 有版本和退役路径。

## 硬规则

- 凡 Ordinary run 进入稳定终态，必须幂等形成 PathMemory。
- completed 只表示运行正常收尾，不能替代 Verification 或 Acceptance。
- 凡语义沉淀必须引用 PathMemory 或其他明确来源事实。
- 凡复用必标记 Experience Candidate。
- 凡入土必经过 Governance Pipeline。
- 凡成为果实必有脱离边界和撤回路径。
- 自动采集 PathMemory 不等于自动召回、自动入土或自动形成 Path Bias。
