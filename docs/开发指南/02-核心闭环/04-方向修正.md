# 方向修正

## 从旧方向吸收什么

AgentArbor 早期材料中有价值的主张包括：

- 从自然语言目标或场景启动。
- 生成完整 AgentApp，而不是零散文件。
- 重视 agent 分工、工具、工作流、提示词、测试和文档。
- 让非专业用户也能把场景转化为可运行智能体应用。

这些内容应继续保留。

## 修正什么

需要修正的是重心：

- 从“应用生成器”修正为“Agent / AgentApp 孕育与演化平台”。
- 从“项目脚手架”修正为“目标、执行、验证、谱系和能力治理闭环”。
- 从“生成 agent 文件”修正为“治理成熟能力并在必要时导出 agent”。
- 从“适配某个平台”修正为“平台适配服务于 AgentArbor 原生语义”。

## 当前写作口径

后续文档中可以继续引用旧资料，但必须明确它是输入材料，而不是当前执行计划。

开发指南只采用已经校正后的稳定口径：

```text
Imagination
  + Seed Cluster 前置成像
  + User Approval Gate
  + Soil 固定资产
  + Root System 持续探索
  + Core Control Cluster 制定和修订 Growth Plan
  + Branch / Leaf 执行
  + Flower 验证证据
  + Run Memory / Path Bias
  + 谱系治理和能力果实
```
