# 养料请求与补充契约

## Plan Package

Plan Package 是 Underground Cognitive Runtime 的初始方向供给，也是 Aboveground Execution Runtime 的正式输入。它可以保存在内存、显式输出目录或未来 `.agentarbor/` 目录中。

Plan 可以记录候选约束，但不能把候选约束自动变成 hard constraint。通过用户确认、治理规则或后续执行层裁决后，候选约束才能进入 active 状态。

child/rootlet 输出只能作为局部材料进入父层 synthesis / convergence。Plan Package 只能接收经过父层综合、去重、来源归因和冲突裁决后的汇总结果。正式 Plan 必须保留候选来源引用和收束审查记录，不能把未裁决候选材料伪装成事实、约束或方向依据。

## Plan 决策记录

Plan 的决策记录至少说明：

- 保留的主方向。
- 合并的方向。
- 淘汰的方向。
- 需要用户确认的冲突。
- 交给 Aboveground 参考的备选方向。
- 方向裁决所依赖的证据、约束和风险。
- 相关 child/rootlet 输出引用和父层 synthesis 引用。

## 风险记录

Plan 的风险记录至少说明：

- 风险名称。
- 风险来源。
- 影响范围。
- 阻断等级。
- 关联证据。
- 缓解方式。
- 是否需要用户确认或治理复核。

## NutrientRequest

NutrientRequest 是 Aboveground 向 Underground 请求养料的运行期契约。它不授权 Aboveground 自建方向探索集群，只表达缺口和用途。

最小字段：

- `requestId`。
- `requestedBy`：Aboveground Execution Runtime、execution agent、Verification 或 Governance。
- `needType`：`evidence`、`soil_asset`、`external_fact`、`constraint_detail`、`context`、`capability_hint`。
- `neededFor`：关联 Plan、执行节点、验证门或治理记录。
- `blockingLevel`：`blocking`、`helpful`、`optional`。
- `currentAssumption`：Aboveground 当前暂用假设。
- `evidenceGap`：缺少什么证据或引用。
- `acceptedFallback`：在无补充时是否允许继续、降级、回退或停止。
- `status`：`requested`、`accepted`、`supplied`、`rejected`、`superseded`。

## NutrientPatch

NutrientPatch 是 Underground 对 NutrientRequest 的结构化回应。

最小字段：

- `patchId`。
- `requestId`。
- `sourcePlanVersion`。
- `newPlanVersion`：可为空；只有方向需要版本化更新时填写。
- `suppliedEvidenceRefs`。
- `soilAssetRefs`。
- `constraintRefs`。
- `externalFactRefs`。
- `contextSupplementRefs`。
- `capabilityHints`。
- `sourceChildOutputRefs`。
- `parentSynthesisRef`。
- `assumptionVerdict`：`supported`、`weakened`、`rejected`、`unknown`。
- `riskUpdates`。
- `executionImpact`：`none`、`continue`、`revise`、`branch`、`rollback`、`stop`。
- `status`：`supplied`、`no_patch_needed`、`requires_user`、`requires_governance`。

## Handoff

Aboveground 只能读取 approved Plan 和可追踪的 Nutrient Patch。Plan 必须说明：

- 要执行的任务。
- 已确认边界。
- 不应再询问用户的问题。
- 仍允许回问用户的问题。
- 不可越过的权限和风险边界。
- 已确认约束和仍待确认的候选约束。
- 允许的执行组织形态。

## 禁止事项

- Plan 不能替代执行验证。
- Plan 中的候选约束不能替代经过确认的 active constraint。
- 单个 child/rootlet 的原始调研输出不能替代经过父层收束审查的方向、证据、风险或养料补充。
- NutrientRequest 不能绕过 Verification。
- NutrientRequest 不能让 Aboveground 自行探索方向。
- 方向再成形不能静默改写目标。
- Plan Revision 不能缺少用户可追踪记录。
- `.agentarbor` 不能复制 Global Soil 固定资产形成第二事实源。
