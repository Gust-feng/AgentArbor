# 叶层（Leaf Agents）- 具体执行个体

## 职责

叶层执行最小工作单元。Leaf Agent 可以是单个模型调用、工具执行者、代码编辑者、测试执行者、资料提取者或其他具体能力个体。

Leaf Agent 不规划全局路线，不决定能力入土，不批准果实脱离。

## 输入与输出

| 项目 | 内容 |
| --- | --- |
| 输入 | TaskSpec、上下文片段、权限、工具能力、验收标准 |
| 输出 | Artifact、EventLog、执行结果、失败证据、验证请求、Root Callback 建议 |

## 执行规则

- 只执行被分配的任务边界。
- 所有关键动作必须进入 EventLog。
- 产物必须通过 ArtifactStore 或等价结构引用。
- 遇到目标、权限、上下文或事实不足时，先报告阻塞，不用猜测补齐。
- 发现根系证据不足时，可以向 Branch System 或 Flower Cluster 提出 Root Callback 建议。

## 禁止事项

- 不跳过 Branch System 私自改全局计划。
- 不用聊天结果替代 Artifact。
- 不私自扩大权限。
- 不把一次任务中的临时执行个体登记为长期 agent。
- 不用上一次 Path Bias 替代本次测试或验收。
