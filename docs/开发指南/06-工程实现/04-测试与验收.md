# 测试与验收

## 测试层级

未来实现至少需要：

- 单元测试：验证状态机、契约、权限和转换逻辑。
- 集成测试：验证目标、资产、能力、工作流、运行时和验证系统协作。
- 任务样例测试：验证自然语言任务可以形成 Task Soil、Plan、Artifact 和 Run Memory。
- 安全测试：验证默认拒绝、最小权限和密钥隔离。
- 导出测试：验证导出包不继承母体权限，且不复制 Plan Package 为长期事实源。
- 回归测试：验证既有能力不会破坏新目标闭环。

## 验收标准

任何功能完成都必须能回答：

- 它服务哪个目标闭环。
- 输入输出是什么。
- 权限边界在哪里。
- 失败如何处理。
- 结果如何验证。
- 谱系如何记录。
- 是否会产生长期能力资产。

如果无法验证、无法审计、无法恢复，就不能进入核心路径。
