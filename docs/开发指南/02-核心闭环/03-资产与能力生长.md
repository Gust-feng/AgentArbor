# 资产与能力生长

## 本地资产是土壤

本地资产包括用户授权的仓库、文档、资料、配置、历史输出、运行环境和工具。它们构成 AgentArbor 的土壤。

土壤的职责是提供稳定资产、历史证据和治理规则，不是自动接收所有运行输出。读取、索引、摘要和引用都必须服从用户授权。

## 能力生长路径

能力从任务中生长，而不是从命名中生长：

```text
任务需要
  -> 临时能力调用
  -> 结果与证据
  -> Run Memory
  -> Experience Candidate
  -> Path Bias
  -> 治理审查
  -> Capability Asset
  -> 复用、导出或修剪
```

## Capability Asset 最小字段

每个长期能力资产至少需要：

- 名称。
- 用途。
- 来源任务或来源说明。
- 输入输出契约。
- 依赖。
- 权限要求。
- 适用范围。
- 不适用条件。
- 版本。
- 验证记录。
- 维护者或维护策略。
- 退役条件。

## Path Bias 与资产晋升

Path Bias 可以在第一次成功任务后形成，但它只是一种倾向，不是长期资产。它的作用是帮助下一次相似任务更快选择候选路径。

当某个 Path Bias 在多次任务中稳定有效，并且验证门、权限边界和失败模式都清楚时，才可以推动 Experience Candidate 进入治理审查。只有通过治理门后，它才能成为工作流片段、能力模板、固定 agent 或果实。

## 修剪是正常机制

能力资产会过时、重复、失效或变得危险。修剪不是失败，而是保持系统健康的必要机制。

修剪方式包括：

- 降级为参考资料。
- 合并到更通用能力。
- 隔离高风险能力。
- 标记废弃。
- 删除导出入口。
- 保留谱系但停止复用。
