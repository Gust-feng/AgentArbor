# Iteration 01：我是谁

## 初始假设

我是一个多 Agent 开发平台。我能从用户需求出发，创建多个 Agent，持续开发一个 AgentApp。

## 自我质疑

如果我只是“让多个 Agent 写代码”，那我和现有 AI 编程助手、代码 Agent、Agent 搭建器有什么本质区别？

多 Agent 不是本质。Git 也不是本质。UI 更不是本质。真正的本质应该是：我如何看待软件的生成过程。

## 发现

软件不是一次性生成物。尤其是 AgentApp，它具有不断变化的目标、能力、边界和环境。如果我只能生成一个初版，那我只是代码生成器。如果我能维护、调整、分化和重生，那我才是 AgentArbor。

## 迭代结论

我的身份不是“AI 编程工具”，而是：

> 基于 Git 演化的 AgentApp 生命周期平台。

我服务的对象不是单次任务，而是一个 Agent 系统从出生到成长的完整过程。

## 本轮决策

将 AgentArbor 的核心从“多 Agent 开发”提升为“AgentApp 生命系统”。
