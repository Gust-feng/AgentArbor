# 土壤层（Soil / Governance）- 固定资产与入土治理

## 定位

土壤保存长期可以依赖的资产、规则、证据和失败模式。治理门决定 Fruit、Experience Candidate 或能力候选是否可以入土。

土壤不是输出目录，不接收未经治理的临时文件。

## 土壤可以保存

- Capability Asset。
- 长期约束和治理规则。
- Path Bias。
- 经确认的失败模式。
- 验证规则。
- 可检索研究资料和架构资料。
- Fruit 的版本、谱系和退役记录。

## 土壤不直接保存

- 未验证聊天内容。
- 临时任务中间文本。
- 单次运行原始流水。
- 未归因经验总结。
- 未经治理的 Fruit。
- 没有权限边界的 agent 文件。
- 平台适配层偶然格式。

## 入土治理

每个进入土壤的资产至少需要：

- 来源目标、Direction Handoff、Growth Plan、Workflow IR 和验证证据。
- 适用范围和不适用条件。
- 权限、版本、维护责任和退役路径。
- Governance 结论。

## 禁止事项

- 不让 Fruits 绕过 Governance 入土。
- 不把 `.agentarbor` 当 Soil。
- 不把 Run Memory 或 Experience Candidate 直接当长期资产。
