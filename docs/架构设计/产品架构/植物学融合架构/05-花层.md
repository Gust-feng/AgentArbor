# 花层（Verification / Maturity）- 验证与成熟判断

## 定位

花层表示验证、评审和成熟度判断。它负责证明产物是否满足目标、约束、权限、测试和验收要求。

花层不是执行层，也不是最终用户确认的替代品。

## 验证内容

- 产物是否满足 TaskSpec。
- hard constraint 是否全部满足。
- soft constraint 是否偏离，偏离理由是否充分。
- preference 是否只影响排序和默认选择。
- 工具、文件、权限和外部调用是否符合声明。
- 是否需要 Nutrient Request 或 Growth Plan Revision。
- 是否可以形成 Fruit。

## 输出

- Verification Report。
- Acceptance Recommendation。
- Constraint Satisfaction Report。
- Maturity Report。
- Nutrient Request Suggestion。
- Governance Review Request。

## 禁止事项

- 不伪造证据。
- 不自行修改 Growth Plan。
- 不让未经验证的 Fruit 入土。
- 不替代用户对目标变化、权限扩大或高风险动作的确认。
