# 植物学语义映射

## 保留范围

植物学语义用于约束长期能力职责，不用于堆设定。当前产品主线是统一 Workbench 下的 Ordinary / 显式 Multi-Agent；下表概念只在真实能力出生时使用，不组成每次请求必经链路。

| 当前概念 | 语义 | 主要输出 | 禁止误用 |
| --- | --- | --- | --- |
| Task Soil | 当前任务临时土壤 | 任务目标、文件/网页/项目引用、临时约束、权限边界、运行材料 | 不能直接变成长期事实 |
| Global Soil | 治理后的长期土壤 | Capability Asset、Path Bias、长期约束、失败模式、长期偏好 | 不能接收未治理临时输出 |
| Underground Cognitive Runtime | 方向智能 | 目标成形、父层综合、裁决、Plan / Nutrient Patch | 不能生成正式执行成果 |
| Plan | 地下到地上的产品级交接对象 | 方向、证据、约束、风险、执行入口、验证要求 | 不能接收单个 child output 直通 |
| Aboveground Execution Runtime | 执行智能 | 文件修改、文档、原型、工具动作、验证结果 | 不能自建方向探索集群 |
| Fruits | 交付物与候选沉淀 | Artifact、Run Memory、Experience Candidate、能力候选 | 不能自动入土 |
| Governance Pipeline | 候选经验入土前的治理过程 | 晋升、拒绝、退役、Capability Asset、Path Bias、Soil Update | 不能省略验证、归因和权限边界 |
| Ring Memory | 多次运行的聚合视图 | 趋势、重复失败、可修剪资产线索 | 不能成为新的事实源 |

## 长期可选能力链

```text
Desktop Shell
  -> Task Soil
  -> Underground Cognitive Runtime
  -> Plan
  -> Aboveground Execution Runtime
  -> Fruits
  -> Governance Pipeline
  -> Global Soil
```

## `.agentarbor` 的位置

`.agentarbor` 不再作为产品概念树的独立节点。它是 Plan Package 的实现/存储形态或默认目录名，用于暂停恢复、版本管理、人类可读、审计复盘、跨进程消费和防 child output 直通执行。

如果文档需要保留“方向交接”说法，只能限定为 Underground 到 Aboveground 的内部边界，不再扩张成宏大的产品节点。

## 设计约束

- Task Soil 负责当前任务，不负责长期沉淀。
- Global Soil 负责长期事实，不接收未治理材料。
- Underground 负责方向成形，不负责正式执行。
- Plan 负责交接，不负责沉淀。
- Aboveground 负责执行和验证，信息不足时发起 Nutrient Request。
- Fruits 负责交付和候选沉淀，不默认继承母体权限。
- Governance Pipeline 负责入土裁决，不创建无证据长期资产。
- Ring Memory 负责观察沉淀，不创建平行事实。
- Path Bias 不能覆盖 hard constraint。
