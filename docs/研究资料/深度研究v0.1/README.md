# 深度研究 v0.1

本目录保存 AgentArbor 早期深度研究的分章节资料。

这些资料包括愿景、设计原则、非目标、术语、研究迭代、系统架构、模型与数据结构、决策框架、AgentApp 标准、图表和 Codex 提示词。它们是理解 AgentArbor 长期形态的重要来源。

- `02-研究迭代/`
- `03-架构/`
- `04-模型与数据结构/`
- `05-决策框架/`

- `07-历史路线资料/`
- `08-图表/`
- `09-Codex提示词/`
- `原始包/`

## 使用规则

本目录是研究资料，不是当前开发计划。采用其中任何设计前，都需要与 `../../开发指南/` 对齐。
