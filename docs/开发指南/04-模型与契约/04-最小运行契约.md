# 最小运行契约

本文件定义进入第一阶段实现前必须冻结的最小运行契约。代码可以晚出生，但这些对象不能含混。

## 内部消息

`ArborMessage` 是 AgentArbor 的内部消息母语。外部协议必须通过 adapter 转换为内部消息，不能直接污染核心模型。

```ts
type ArborMessage<TPayload = unknown> = {
  id: string;
  traceId: string;
  taskId?: string;
  parentTaskId?: string;
  from: { id: string; role?: string; cluster?: string };
  to?: { id: string } | { role: string } | { group: string };
  type: ArborMessageType;
  intent: string;
  payload: TPayload;
  artifacts?: ArtifactRef[];
  requiredCapabilities?: string[];
  priority?: 'low' | 'normal' | 'high' | 'critical';
  permissions?: {
    canRead?: string[];
    canWrite?: string[];
    canExecute?: string[];

  createdAt: string;
};
```

## Root Callback

Root Callback 是地上组织回调地下组织的补探机制。它由 Core Control Cluster、Branch Agent 或 Flower Cluster 触发，输出新的 Root Brief 版本或明确“不需要重探”的证据。

```ts
type RootCallback = {
  id: string;
  goalId: string;
  triggeredBy: {
    agentId: string;
    layer: 'core_control' | 'branch' | 'flower';
  };
  reason:
    | 'insufficient_information'
    | 'verification_failed'
    | 'path_bias_invalid'
    | 'goal_changed'
    | 'assumption_invalid'
    | 'permission_or_cost_invalid';
  question: string;
  evidenceRefs: string[];
  requestedMode: 'lateral' | 'deep';
  status: 'requested' | 'completed' | 'not_needed';
  outputRootBriefId?: string;
  outputRootBriefVersion?: number;
  noRerootingEvidence?: string[];
  createdAt: string;
  completedAt?: string;
};
```

## 任务状态

```text
Draft
Imaging
SeedReady
Ready
Exploring
Planning
Assigned
Running
Blocked
ReRooting
Revising
Verifying
AcceptedForDelivery
Delivered
Archived
Cancelled
Failed
```

守卫规则：

- `Exploring` 前必须有已确认的 SeedPacket。
- `Planning` 前必须有 RootBrief。
- `Assigned` 前必须有 GrowthPlan。
- `ReRooting` 必须由 RootCallback 进入。
- `Revising` 必须引用新的 RootBrief 版本或无需重探证据。
- `Delivered` 必须有至少一个产物。
- `AcceptedForDelivery` 必须经过 Verification。
- `Delivered` 必须经过 Acceptance。
- `Archived` 前必须写入 EventLog。
- `Archived` 前必须写入 RunMemory，或明确记录没有可沉淀内容的原因。
- 高风险操作必须经过 `user_approval.requested`。

## 第一阶段限制

第一阶段只实现内存版接口和最小事件链。不实现 A2A Adapter、MCP Adapter、AG-UI Adapter、完整模型调用、长期记忆治理、自主演化、复杂权限系统和数据库持久化。

第一阶段仍必须保留 `SeedPacket`、`RootBrief`、`GrowthPlan`、`RootCallback`、`GrowthPlanRevision`、`RunMemory`、`ExperienceCandidate` 和 `PathBias` 的最小结构。否则系统只能证明自己会执行一次任务，不能证明自己会把一次任务变成下一次任务的有效倾向。
