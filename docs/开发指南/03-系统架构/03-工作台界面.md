# 工作台界面

## 界面目标

AgentArbor Desktop 不是营销首页，也不是单纯调试面板。它是桌面通用 Agent 的工作台：用户提交任务、绑定工作区上下文、查看 Plan 和交付成果，同时能监督 agent 协作过程。

用户只面对一个 Desktop Shell，不应该被迫理解 Underground / Aboveground 两个内部运行时入口。

## Desktop Shell 结构

```text
Desktop Shell
  - Task Inbox / 输入区
  - Workspace Context / 文件、项目、网页上下文
  - Main Canvas / 当前任务主画布
  - Artifact Area / 结果与 Plan
  - Observation Panel / 监督面板
```

### Task Inbox

承接自然语言任务、文件夹、项目、文档、网页和补充说明。它只创建 Task Soil，不直接创建长期 Soil 资产。

### Workspace Context

展示本轮任务可用的文件、项目、网页、外部资料和权限边界。上下文以引用进入 Task Soil，避免复制大段内容形成第二事实源。

### Main Canvas

主画布服务用户完成任务。它展示：

- 当前任务目标和状态。
- Plan 摘要。
- 交付结果。
- 结论、一句话理由和关键证据引用。
- 可展开解释：为什么选 A、为什么不选 B、主要风险、不确定性和相关 agent 摘要。

主画布解释“这个结果为什么合理”，不承担完整监督面板职责。

### Artifact Area

展示文档、代码改动、原型、报告、Plan Package 和验证结果。`.agentarbor` 目录若出现，只作为 Plan Package 的存储形态展示，不作为独立产品节点。

### Observation Panel

监督面板解释“agent 集群如何形成这个结果”。它展示：

- agent run tree。
- child 输出摘要。
- 父层 synthesis。
- convergence 事件。
- 模型和工具 refs。
- budget。
- trace。
- 安全 reasoningTrace 投影。

Panel 不展示 raw prompt、raw provider response、raw tool output、hidden reasoning、密钥或 token。

## 三层解释结构

```text
主画布默认：
  结论
  一句话理由
  关键证据引用

主画布展开：
  为什么选 A
  为什么不选 B
  主要风险
  不确定性
  相关 agent 摘要

Observation Panel：
  agent run tree
  child 输出摘要
  父层 synthesis
  convergence 事件
  模型和工具 refs
  budget
  trace
```

用户在结果中追问“为什么推荐方案 A 而不是方案 B”时，应先在 Main Canvas 的对应结果处获得解释摘要，再选择是否打开 Panel 查看完整监督 trace。

## 界面边界

UI 不能直接绕过权限层访问本地资产，不能直接写长期能力注册表，也不能把平台适配格式展示成 AgentArbor 原生事实。
