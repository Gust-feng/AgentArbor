# 权限与安全资料卡

## 1. 目标

AgentArbor 未来会生成代码、运行命令、接入工具、调用模型和读取项目文件。

权限必须是核心模型，而不是提示词里的提醒。

## 2. P0 Gate 资产

```text
gate.permission
gate.network_policy
gate.secret_broker
gate.human_approval
```

## 3. gate.permission

```text
类别：Gate
接口：policy engine
风险：High
来源链接：https://owasp.org/www-project-top-10-for-large-language-model-applications/
当前动作：定义 Low/Med/High action tiers
```

沉淀结论：

* 所有 ToolCall 必须先过 PermissionGate。
* 权限按动作分级，而不是按 Agent 名字授权。
* 高风险动作必须要求人工确认或专用策略。

建议动作等级：

```text
Low：只读、结构验证、离线分析。
Medium：写工作区、运行测试、应用补丁。
High：联网、读密钥、执行任意命令、提交/发布。
```

## 4. gate.network_policy

```text
类别：Gate
接口：allow/deny list
风险：High
来源链接：https://docs.docker.com/ai/sandboxes/security/isolation/
当前动作：建立 domain allowlist
```

沉淀结论：

* 测试阶段默认断网。
* 构建阶段是否联网由 BuildRecipe 显式声明。
* 外部 API、包管理器、Git 远端必须进入 allowlist。

## 5. gate.secret_broker

```text
类别：Gate
接口：credential proxy
风险：High
来源链接：https://docs.docker.com/ai/sandboxes/security/isolation/
当前动作：实现 ephemeral secret API
```

沉淀结论：

* Agent 不直接持有真实密钥。
* 密钥按任务和工具临时注入。
* 日志和输出必须经过 secret scrubber。

## 6. gate.human_approval

```text
类别：Gate
接口：UI/policy
风险：Medium
当前动作：定义 approval triggers
```

沉淀结论：

触发人工确认的情况至少包括：

* 高风险 shell 命令。
* 访问外网。
* 读取或注入密钥。
* 写入非工作区路径。
* 创建提交、PR、发布或部署。
* 引入新的外部 MCP / Skill / Plugin。

## 7. 默认安全姿态

```text
default_network: deny
default_filesystem: workspace_only
default_secrets: deny
default_shell: deny
default_external_assets: untrusted
```

AgentArbor 的安全边界应由策略引擎强制执行，而不是由 Agent 自觉遵守。
