# 技术主线

## 默认方向

未来实现以 TypeScript 自研架构为主：

- 语言：TypeScript。
- 本地服务：Node.js。
- 持久化：本地嵌入式数据库优先。
- 前端：TypeScript Web 技术栈。
- 测试：单元测试、集成测试、任务样例测试、安全边界测试。
- 外部系统：通过 adapter 接入。

## 实现原则

- 先稳定模型，再写运行时。
- 先做闭环，再做复杂生态。
- 先保证权限和验证，再扩展自动化。
- 先证明 AgentApp 可出生，再谈大规模 agent 市场。

## 不提前引入

除非进入明确实现阶段，否则不引入包管理器、构建系统、运行时代码或测试框架。
