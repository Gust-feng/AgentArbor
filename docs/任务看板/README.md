# 历史任务看板

本目录只保留 AgentArbor 早期 Trellis 任务状态的人类态势快照，用于理解历史演进背景。

`.trellis/tasks/` 不再作为当前任务、阶段推进、检查点、约束或工作流状态的源数据。这里不创建第二套计划系统，也不再通过 Trellis 任务刷新当前方向。

最后更新：2026-05-16

## 文件入口

- [看板](看板.md)：历史快照，说明旧看板为何冻结，以及当前应以哪些事实源为准。
- [规则](规则.md)：冻结后的维护规则，防止历史看板重新变成任务源。

## 看板范围

- 历史脉络：只保留对理解产品转向有价值的信息。
- 当前事实：以 `AGENTS.md`、`docs/开发指南/`、当前 ADR 和用户最新指令为准。
- 后续流程：进入正式开发指南、ADR、任务契约文档或代码实现边界，不进入 `.trellis/tasks`。

## 边界

- Trellis task 不是当前任务源。
- 本目录是历史可读视图。
- `docs/开发指南/` 是稳定开发口径。
- `docs/研究资料/` 和 `docs/架构设计/` 是思想来源与长期判断。
- 根目录不新增 `Plan/`、`Plans/`、`plans/` 或 `PLANS.md`。
