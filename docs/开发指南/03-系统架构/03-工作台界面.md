# 工作台界面

## 界面目标

未来工作台不是营销首页，而是面向真实开发和治理的操作界面。它应该让用户清楚看到 Imagination、Seed Packet、Soil、Root Brief、Growth Plan、Branch / Leaf / Flower、Root Callback、工作流、执行、验证、Run Memory、Path Bias 和能力生长状态。

## 主要视图

### 目标视图

显示目标、约束、验收标准、状态、阻塞点和变更记录。

### 智能体应用视图

显示智能体应用的 Branch / Leaf / Flower 组织、职责边界、能力声明、工作流、工程结构、测试和文档。

### 执行视图

显示当前 Workflow IR 的任务图、运行状态、工具调用、文件变化、失败原因和恢复点。

### 验证视图

显示测试结果、检查清单、人工确认项、失败证据和修复建议。

### 沉淀视图

显示本次任务的 Run Memory、Experience Candidate、Path Bias、复用条件、不适用条件、失败模式和权限结论。

### 谱系视图

显示目标、AgentApp、能力资产、导出包和子 agent 之间的来源关系。

### 治理视图

显示 Experience Candidate、Capability Asset、Path Bias 晋升状态、权限要求、评估结果、版本、导出状态、修剪建议和退役记录。

## 界面边界

UI 不能直接绕过权限层访问本地资产，不能直接写长期能力注册表，也不能把平台适配格式展示成 AgentArbor 原生事实。
