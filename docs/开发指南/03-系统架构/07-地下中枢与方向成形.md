# 地下中枢与方向成形

## 定位

Underground Center 是 AgentArbor 的地下中枢。它把用户想象、土壤事实、约束、风险和证据整理成地上可接管的方向交接包。

地下中枢不属于地上执行组织。它不执行正式任务，不写长期资产，不生成 Growth Plan。

## 输入与输出

输入包括：

- 用户原始目标、背景和补充信息。
- Soil 中的长期事实、Capability Asset、Path Bias、治理规则和失败模式。
- 初始约束、偏好、权限、成本、时间、安全和验收要求。
- 外部事实核验结果和内部证据。

输出是 `.agentarbor` 方向交接包：

```text
.agentarbor/
  direction.md
  constraints.json
  soil-refs.json
  evidence-index.md
  open-questions.md
  escalation-rules.md
  growth-entry.json
  handoff.meta.json
```

## 固定职责

地下中枢是固定低自由度集群，建议包含：

| 成员 | 职责 |
| --- | --- |
| Goal Framer | 理解用户想象，形成目标、非目标和验收标准 |
| Constraint Framer | 整理权限、成本、技术边界、人工确认和资产治理约束 |
| Evidence Explorer | 检索 Soil、历史运行、能力资产和外部事实 |
| Assumption Mapper | 列出假设、缺失信息和待确认点 |
| Direction Critic | 反驳、找漏洞、防局部最优 |
| Risk Gate | 检查权限、成本、风险和不可逆动作 |
| Direction Synthesizer | 汇总方向、证据、ConstraintRef、升级条件和 Growth Entry |

## 用户确认循环

```text
User Imagination
  -> Underground Center
  -> Direction Draft
  -> User Review when needed
  -> .agentarbor Direction Handoff
```

用户只在必要处确认。当地下中枢已经拥有足够目标、约束、权限和证据时，应直接形成方向交接包；当目标冲突、权限不清、关键事实缺失、高风险动作或长期治理冲突出现时，必须升级给用户。

## 禁止事项

- 不生成 Growth Plan。
- 不调度地上生长组织。
- 不创建 Capability Asset。
- 不把方向交接包当长期事实源。
- 不把候选约束自动变成长期约束。
- 不绕过用户确认门执行高风险动作。
- 不把 Soil 内容复制进 `.agentarbor` 形成第二事实源。
