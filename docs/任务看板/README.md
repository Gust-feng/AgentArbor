# 任务看板

本目录是 AgentArbor 的人类态势看板资产，用来把 Trellis 任务状态压缩成可阅读、可续接、可判断方向的视图。

`.trellis/tasks/` 仍然是任务、阶段推进、检查点和工作流状态的唯一源数据。这里不创建第二套计划系统，也不为每个任务额外保存一个看板文件。

最后更新：2026-05-05

## 文件入口

- [看板](看板.md)：主视图，展示前置任务、当前任务和未来方向。
- [规则](规则.md)：维护规则，说明看板如何更新、压缩和保持与 Trellis 的边界。

## 看板范围

- 前置任务：保留关键已完成任务的压缩脉络，帮助理解当前状态从哪里来。
- 当前任务：保留最具体的推进信息，包括当前指针、活跃任务、下一步、阻塞点和验收判断。
- 未来任务：只写方向和触发条件，不写成已承诺的任务，也不替代 Trellis 任务创建。

## 边界

- Trellis 是任务源。
- 本目录是可读视图。
- `docs/开发指南/` 是稳定开发口径。
- `docs/研究资料/` 和 `docs/架构设计/` 是思想来源与长期判断。
- 根目录不新增 `Plan/`、`Plans/`、`plans/` 或 `PLANS.md`。

维护本目录时使用 repo-local skill：`trellis-task-board`。
